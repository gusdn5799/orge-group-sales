데이터 관리

회차 추가 (구글 시트 열기)
  1. 스마트스토어에서 주문조회 엑셀을 받습니다. 비밀번호가 걸린 파일은 엑셀에서 비밀번호를 풀고 다시 저장합니다.
  2. 구글 시트의 해당 주문 탭(주문_…)에서 파일 → 가져오기 → 업로드 → "현재 시트에 추가"로 넣습니다.
  3. "회차" 탭 맨 아래에 벤더, 인플루언서, 회차명, 시작일, 종료일을 한 줄 적습니다. 처음 파는 상품이면 "상품" 탭에 상품번호와 벤더, 인플루언서도 적습니다.
  4. 시트 메뉴 대시보드 → 반영하기를 누릅니다. 구매자 이름·ID·수취인은 이때 고객키로 바뀌고 지워집니다.
  5. 이 화면에서 "반영된 데이터 다시 불러오기"를 누릅니다.

회차 분석 보고 메일

회차를 고르고 버튼을 누르면 그 회차의 매출, 주문·고객, 품목, 판매 흐름과 전체 회차 표를 메일로 보냅니다. 가격표가 비어 있는 회차는 보낼 수 없습니다.
