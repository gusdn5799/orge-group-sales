데이터 관리

회차 추가 (구글 시트 열기)
  1. 스마트스토어에서 주문조회 엑셀을 받습니다. (단품 상품, ALL세트 상품 각각)
  2. 구글 시트의 "주문_단품" 탭에서 파일 → 가져오기 → 업로드 → "현재 시트에 추가"로 단품 엑셀을 넣습니다. "주문_ALL세트" 탭에도 같은 방법으로 넣습니다.
  3. "회차" 탭 맨 아래에 회차명, 시작일, 종료일을 한 줄 적습니다.
  4. 시트 메뉴 대시보드 → 반영하기를 누릅니다. 구매자 이름·ID·수취인은 이때 고객키로 바뀌고 지워집니다.
  5. 이 화면에서 "반영된 데이터 다시 불러오기"를 누릅니다.

접속 기록

최근 기록부터 최대 1,000건. 같은 내용이 구글 시트 "접속기록" 탭에도 쌓입니다.
